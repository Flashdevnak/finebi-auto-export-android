# Thai Screen Translate 1.1

แอป Android สำหรับแปลข้อความภาษาจีน **ทั้งหน้าจอ** เป็นภาษาไทยแบบต่อเนื่อง

- จับทั้งหน้าจอด้วย MediaProjection
- OCR ภาษาจีนด้วย ML Kit
- แปลจีน → ไทยด้วย ML Kit Translation แบบ on-device
- วางคำแปลทับตำแหน่งข้อความเดิมทั่วทั้งจอ
- สแกนเป้าหมายทุกประมาณ 0.7 วินาที (ถ้ารอบก่อนยังประมวลผลอยู่จะไม่ซ้อนงาน)
- Cache ประโยคที่เคยแปล เพื่อลดหน่วงและประหยัดแบต
- ใช้กับ Hongguo / Douyin / แอปจีนอื่นได้โดยไม่ต้องแก้ APK ต้นทาง
- ไม่ต้อง Root

## วิธีใช้
1. เปิดแอป
2. อนุญาต `แสดงทับแอปอื่น`
3. กด `เริ่มแปลทั้งหน้าจอ`
4. กดยืนยันสิทธิ์จับภาพหน้าจอของ Android
5. เปิดแอปจีนที่ต้องการ แปลจะทำงานต่อเนื่อง
6. ครั้งแรกต้องต่ออินเทอร์เน็ตเพื่อดาวน์โหลดโมเดลแปลภาษา

## ข้อจำกัด
- หน้า/วิดีโอที่ใช้ FLAG_SECURE หรือ DRM อาจจับภาพไม่ได้
- OCR อาจคลาดเคลื่อนเมื่อฟอนต์เล็ก ภาพเบลอ หรือพื้นหลังซับซ้อน
- แอปนี้แปลข้อความที่มองเห็นบนหน้าจอ ไม่ได้แก้ไขแอปต้นทาง
